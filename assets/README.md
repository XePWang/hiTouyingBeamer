# 展示资源

| 资源 | 来源与用途 |
| --- | --- |
| `hit-logo.png` | 用户提供的 `PPT模板.pptx` 中的校名标识，与 `cuDilithium-方班汇报` 使用同一素材 |
| `figures/amdahl.pdf` | `build-plots.py` 根据 Amdahl 解析式生成 |
| `figures/roofline.pdf` | `build-plots.py` 根据归一化 Roofline 解析式生成 |
| `figures/pipeline.pdf` | 从 `figures/pipeline.mmd` 生成的 Mermaid 矢量图 |
| `../vi/` | 上游模板随附的视觉素材，保留上游文件 |

图表中的字体来自本模板 `fonts/` 目录。解析图和流程图源文件随模板提供，采用与模板相同的 LPPL-1.3c 许可。

校名、校徽、校园视觉素材的权利归相应权利人。本项目将其用于哈尔滨工业大学的学术汇报与交流；LPPL 和字体 OFL 不构成对这些标识的额外授权。其他机构使用模板时通过 `\hitlogo{...}` 指定其有权使用的标识。`vi/` 的上游来源说明为网络素材经处理，当前示例使用 `hit-logo.png`。
